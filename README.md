# java-racingcar-precourse
자동차 경주 게임 기능 목록

 1.입력

  1.1.경주할 자동차 이름들을 쉼표(,)로 구분하여 입력받는다.

  1.2.시도할 횟수를 입력받는다.

 2.유효성 검사

  2.1.자동차 이름이 5자를 초과하면 IllegalArgumentException을 발생시킨다.

  2.2.자동차 이름 입력이 비어있거나, 쉼표로 끝나거나, 연속된 쉼표를 포함하면 IllegalArgumentException을 발생시킨다.

  2.3.각 자동차의 이름이 비어있는 경우 IllegalArgumentException을 발생시킨다.

  2.4.시도할 횟수가 숫자가 아닌 경우 IllegalArgumentException을 발생시킨다.

  2.5.시도할 횟수가 1 미만의 숫자인 경우 IllegalArgumentException을 발생시킨다.

 3.게임 로직

  3.1.입력받은 이름으로 자동차 객체를 생성한다.

  3.2.각 자동차는 이름과 위치 데이터를 가진다.

  3.3.0에서 9 사이의 무작위 값을 생성한다.

  3.4.무작위 값이 4 이상이면 자동차를 전진시킨다. (위치 1 증가)

  3.5.무작위 값이 3 이하이면 자동차는 멈춘다.

 4.게임 진행

  4.1.시도할 횟수만큼 전체 자동차의 이동 로직을 반복한다.

  4.2.각 횟수(라운드)가 끝날 때마다 모든 자동차의 현재 상태(이름 : ---)를 출력한다.

 5.출력

  5.1."실행 결과" 헤더를 출력한다.

  5.2.게임이 모두 끝난 후, 가장 멀리 간 자동차(들)를 우승자로 선정한다.

  5.3.단독 우승자인 경우 "최종 우승자 : [이름]" 형식으로 출력한다.

  5.4.공동 우승자인 경우 "최종 우승자 : [이름1], [이름2]" 형식으로 쉼표로 구분하여 출력한다.
